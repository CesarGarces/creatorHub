# Design tokens

Defined once with Tailwind v4's `@theme` in each app's `globals.css`
(`--color-*`, `--radius-*`, `--font-*`) and used through utilities such as
`bg-surface`, `text-text-muted`, `border-border`, `rounded-xl`.

### Contrast (WCAG 2 AA, enforced)

Every text token meets **4.5:1** on every surface (`bg`, `surface`,
`surface-elevated` and the 10–20% status tints); axe checks it on every
story and every app screen (`apps/e2e/fixtures/a11y.ts`).

| Pair                                                   | Ratio           |
| ------------------------------------------------------ | --------------- |
| `text-dim` on `surface-elevated` · on the primary tint | 4.96:1 · 4.75:1 |
| `text-muted` on `surface-elevated`                     | 6.18:1          |
| `primary-foreground` on `primary`                      | 8.31:1          |
| white on `error-solid`                                 | 4.83:1          |
| `error` on its tint (`bg-error-light`)                 | 5.9:1           |

- White text on `bg-primary` (2.3:1) fails — use `text-primary-foreground`.
- Don't dim readable text with `opacity-*` (cards "coming soon", inactive
  rows, done sessions): use a quieter token, `grayscale`, dashed borders or
  line-through instead. Only disabled controls may fade.
- On dark tints use the `-400` shades (`text-red-400`, `text-blue-400`,
  `text-purple-400`); `-500` drops under 4.5:1.
- Links inside text are underlined (colour alone is not enough).

## Radii

| Token         | Value | Typical use            |
| ------------- | ----- | ---------------------- |
| `rounded-md`  | 8px   | Small buttons, inputs  |
| `rounded-lg`  | 12px  | Buttons, fields, menus |
| `rounded-xl`  | 16px  | Cards, dialogs, tables |
| `rounded-2xl` | 1rem  | Chat bubbles, previews |

## Layers (z-index)

| Layer                                | z-index       |
| ------------------------------------ | ------------- |
| Chat backdrop / panel / button (web) | 90 / 95 / 100 |
| Navigation drawer backdrop / drawer  | 105 / 110     |
| Asset preview / share modal (web)    | 120 / 130     |
| Dialogs, popovers, dropdowns         | 99999         |
